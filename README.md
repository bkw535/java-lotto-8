# java-lotto-precourse

## 구현 기능
### 1. 입력 기능
  * 로또 구입 금액 입력
    * 구입 단위는 1,000 단위로 입력
  * 당첨 번호 입력
    * 로또 번호는 1부터 45 사이의 숫자
    * 번호는 쉼표(,)를 기준으로 구분
    * 당첨 번호는 중복된 숫자 금지
  * 보너스 번호 입력
    * 당첨 번호와 중복 금지
---
### 2. 로또 발행
  * 구입 금액에 따라 발행할 로또 개수를 계산
  * 각 로또는 `Randoms.pickUniqueNumbersInRange(1, 45, 6)`을 사용해 자동 생성
    * 뽑은 숫자들은 오름차순 정렬
---
### 3. 당첨 계산
  * 각 로또의 당첨 개수를 계산
    * 동일한 번호의 개수를 비교하여 일치하는 개수 계산
    * 5개 일치 시 보너스 번호 포함 여부 판별
  * 당첨 금액 별 총 수익률 계산
---
### 4. 출력 기능
  * 발행된 로또 번호 목록 출력
  * 당첨 내역 출력
  * 총 수익률 출력
---
### 5. 예외 처리
  * 잘못된 입력 시 `IllegalArgumentException` 발생 후 에러 메시지 출력
  * 에러 메시지는 "[ERROR]"로 시작
  * 에러가 발생한 부분부터 다시 입력
  * 구입 금액
    * 입력한 금액이 1,000 단위로 나누어 떨어지지 않는 경우
    * 입력한 금액이 숫자가 아닌 경우
  * 당첨 번호
    * 당첨 번호에 1부터 45 사이의 숫자가 들어 있지 않은 경우
    * 구분자가 쉼표가 아닌 경우
    * 입력한 당첨 번호가 숫자가 아닌 경우
  * 보너스 번호
    * 숫자가 아닌 경우
    * 당첨 번호에 1부터 45 사이의 숫자가 들어 있지 않은 경우
    * 당첨 번호와 중복될 경우
